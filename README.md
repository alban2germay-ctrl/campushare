## 🚀 Comment Collaborer sans Friction (Guide pour Mathys)

### Méthode 1 : Zéro Installation (Dans ton navigateur Chrome)
1. Va sur ce dépôt GitHub sur ton ordinateur.
2. Appuie sur la touche **`.`** (le point) de ton clavier.
3. L'éditeur visuel s'ouvre directement dans Chrome.
4. Ouvre `ESPACE_MATHYS.md`, écris tes notes, fais `Ctrl + S`, puis clique sur le bouton bleu **« Commit & Push »**.

### Méthode 2 : Avec GitHub Desktop
1. Installe **GitHub Desktop**.
2. Clique sur **« Fetch origin »** pour récupérer le travail.
3. Modifie tes fichiers, puis clique sur **« Push origin »** pour synchroniser.
